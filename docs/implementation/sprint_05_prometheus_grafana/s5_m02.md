# S5-M02 - Prove persistence and import the Kubernetes dashboard

**Sprint:** S5 Prometheus & Grafana (PDF Step 5 (3 h))  
**Owner:** C  
**Estimate:** 1 h  
**Depends on:** S5-M01  
**Teacher's requirement:** PDF Step 5 'Import the Kubernetes dashboard'; Deliverable 4 'exported JSON dashboard'

## Why this issue exists
Two rubric items: persistent EBS storage works, and a Kubernetes dashboard exists and is exported as JSON in Git.

## Steps
1. Persistence test: create a small custom dashboard in Grafana, delete the Grafana pod (`kubectl delete pod -n monitoring -l app.kubernetes.io/name=grafana`), wait for the new pod, confirm the dashboard is still there. Screenshot.
2. The chart already provisions several Kubernetes dashboards. Import one more Kubernetes dashboard from grafana.com (Dashboards -> New -> Import) and choose a Prometheus data source.
3. Make the dashboard show the `retail` namespace pods (CPU/memory).
4. Export the JSON (Share -> Export) to dashboards/kubernetes-retail.json and commit it.

kubectl get pvc -n monitoring
