# S4-M01 - Jenkins EC2 instance via Terraform (t3.small, LabInstanceProfile, user-data)

**Sprint:** S4 Jenkins CI/CD Pipeline (PDF Step 4 (3.5 h))  
**Owner:** B  
**Estimate:** 1.5 h  
**Depends on:** S2-M02  
**Teacher's requirement:** PDF section 2 (CI/CD layer) + Step 4 'Provision the Jenkins EC2 instance via Terraform user-data (Docker, Trivy, kubectl, aws-cli)'

## Why this issue exists
The PDF says 'attach the existing LabRole instance profile'. In Learner Lab the pre-created instance profile is named LabInstanceProfile and it contains LabRole. Attaching it gives Jenkins AWS access without any key.

## Steps
1. terraform/modules/jenkins: aws_instance, t3.small, AMI = latest Amazon Linux 2023 (aws_ami data source), subnet = public subnet, iam_instance_profile = "LabInstanceProfile".
2. Security group: SSH 22 and Jenkins 8080 only from your own IP (variable) plus GitHub's webhook ranges for 8080 (`curl -s https://api.github.com/meta | jq .hooks`). Everything else closed. (Deliverable 6: restricted ports.)
3. user-data installs: docker, git, java 17+, jenkins (LTS), aws-cli v2, kubectl, trivy; adds user jenkins to group docker; creates a 2 GB swap file (t3.small has only 2 GB RAM and a Java build can run out of memory).
4. Output: jenkins_public_ip and URL. Read the initial admin password from /var/lib/jenkins/secrets/initialAdminPassword via SSM Session Manager or SSH (until S4-M02 automates it).

## Useful commands
```bash
terraform apply
curl -I http://<jenkins_ip>:8080
# on the instance:
docker --version; trivy --version; kubectl version --client; aws sts get-caller-identity   # must show LabRole
```

## Done when (acceptance checklist)
- [ ] Jenkins login page reachable from my IP only.
- [ ] `aws sts get-caller-identity` on the instance shows the LabRole (no keys configured).
- [ ] docker, trivy, kubectl, aws cli installed; jenkins can run `docker ps`.
- [ ] No inbound rule is open to 0.0.0.0/0.
- [ ] PR reviewed by a different member and merged; commit messages start with the local ID
- [ ] Nothing secret committed (keys, tokens, kubeconfig, tfstate)

## Watch out
- RISK: t3.small (2 GB) may be too small for building the Java ui image. Swap helps; if the build is killed (OOM), switch the variable to t3.medium and tell the team.
- The public IP changes at every `make up` (we destroy everything each session): see S4-M04.
