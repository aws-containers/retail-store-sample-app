## Why this issue exists
Automatic scale-out when the UI is busy.

## Steps
1. k8s/hpa/ui-hpa.yaml (autoscaling/v2): minReplicas 2, maxReplicas 5, CPU averageUtilization 50-60%.
2. Requires: metrics-server working (S2-M05) and requests.cpu on ui (S3-M04). Check `kubectl get hpa -n retail` shows a real percentage, not <unknown>.
3. Add to kustomization so it is deployed with the app.

kubectl get hpa -n retail
kubectl describe hpa ui -n retail
