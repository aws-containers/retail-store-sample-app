# S3-M05 - End-to-end smoke test script

**Sprint:** S3 Retail Store & DynamoDB (PDF Step 3 (2.5 h))  
**Owner:** B  
**Estimate:** 45 min  
**Depends on:** S3-M03, S3-M04  
**Teacher's requirement:** Deliverable 3 and 7 (reproducibility)

## Why this issue exists
A repeatable check that the whole store works, used after every `make up`, after pipeline deploys, and during the demo.

## Steps
1. scripts/smoke_test.sh: discover the ui hostname with kubectl, then curl the home page and a catalog page; fail (exit 1) on non-200.
2. Add checks: `kubectl get pods -n retail` all Ready; a cart item written to DynamoDB (or just check the table is reachable).
3. Print PASS/FAIL per check and a final summary.

## Useful commands
```bash
bash scripts/smoke_test.sh
```
