# S3-M03 - Connect the cart service to the DynamoDB table

**Sprint:** S3 Retail Store & DynamoDB (PDF Step 3 (2.5 h))  
**Owner:** B  
**Estimate:** 1 h  
**Depends on:** S3-M02, S2-M06, S2-M04  
**Teacher's requirement:** PDF section 3, Step 3 'connect cart to the DynamoDB table created by Terraform'; Deliverable 5

## Why this issue exists
By default the cart stores data in a DynamoDB-local pod. The assignment wants the managed AWS table `shopops-carts`. The cart reads its settings from environment variables.

## Steps
1. Find the cart's ConfigMap/env in the pinned manifest: `grep -n RETAIL_CART_PERSISTENCE k8s/base/upstream-kubernetes.yaml`.
2. Create a kustomize patch (k8s/patches/cart-dynamodb.yaml) that sets: RETAIL_CART_PERSISTENCE_PROVIDER=dynamodb, RETAIL_CART_PERSISTENCE_DYNAMODB_TABLE_NAME=shopops-carts, RETAIL_CART_PERSISTENCE_DYNAMODB_CREATE_TABLE=false, and AWS_REGION=us-east-1.
3. REMOVE from the cart config: RETAIL_CART_PERSISTENCE_DYNAMODB_ENDPOINT (it points to the local pod) and the fake AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY values that the local setup uses. If they stay, the SDK uses the fake keys instead of the node role.
4. Apply, restart the cart deployment, add items in the UI, then check the table with the AWS CLI.
5. Restart the cart pod (`kubectl rollout restart deploy/cart -n retail`): the items must still be there. Optionally scale the local `carts-dynamodb` deployment to 0 and note it.

## Useful commands
```bash
aws dynamodb scan --table-name shopops-carts --max-items 5
kubectl logs deploy/cart -n retail --tail=50
kubectl exec deploy/cart -n retail -- env | grep -E 'PERSISTENCE|AWS_'
```

- [ ] PR reviewed by a different member and merged; commit messages start with the local ID

## Watch out
- Pods get AWS credentials from the node's instance metadata only if the hop limit is 2 (set in S2-M04). If logs show credential/timeout errors, test from a pod: `kubectl run t --rm -it --image=amazon/aws-cli -- sts get-caller-identity`.
- Deployment/ConfigMap names may differ from this text: trust what you find in the file.
